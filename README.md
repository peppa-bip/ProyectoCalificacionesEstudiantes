# Proyecto: Sistema de Calificaciones

* **Descripción:** Programa en Python diseñado para almacenar, consultar, modificar y procesar un conjunto de calificaciones de estudiantes utilizando arreglos y vectores.
* **Objetivo:** Comprender y aplicar los conceptos de arreglos, índices, ciclos y condicionales en la resolución de un problema práctico.
* **Lenguaje utilizado:** Python
* **Funcionalidades desarrolladas:**
  - Mostrar todas las calificaciones.
  - Consultar una calificación específica mediante su índice.
  - Calcular el promedio general de la clase.
  - Identificar la nota más alta y la más baja.
  - Contar estudiantes aprobados y reprobados con condiciones `if`.
  - Modificar una calificación existente.
  - Mostrar el vector actualizado.
* **Instrucciones para ejecutar el programa:**
  1. Tener instalado Python en el equipo.
  2. Descargar o clonar el repositorio.
  3. Abrir la terminal en la carpeta del proyecto y ejecutar: `python main.py`
